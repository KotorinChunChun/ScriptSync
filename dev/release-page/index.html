読みあわせ
ScriptSync

台本を一文ずつ録音して、音声ファイルにまとめるアプリです。

読み直した部分は別のテイクとして残せます。聞き比べて使うテイクを選び、前後の無音を調整して、WAVやFLACに出力します。

できること

  • Markdown・テキストの台本を取り込み、文ごとに録音
  • 複数テイクの試聴・選択、波形を見ながら前後をトリミング
  • 音量や文の間隔を調整し、まとめて、または分割して出力
  • Whisperによる文字起こしで読みを確認（追加環境の導入が必要）

ダウンロード

現在はベータ版を配布しています。初めて使うPCでは、下の手順で証明書を登録してください。

インストール・更新App Installerで導入。起動時に更新を確認します。.appinstaller 本体をダウンロードパッケージ版 0.0.6.4・Windows x64.msix 署名証明書初回導入用・発行元 KotorinChunChun.cer

初めてインストールする

  1. 「署名証明書」をダウンロードして開き、発行先が KotorinChunChun であることを確認します。
  2. 「証明書のインストール」で「ローカル コンピューター」を選びます。管理者の許可が必要です。
  3. 「証明書をすべて次のストアに配置する」を選び、「信頼されたユーザー」に登録します。
  4. 「インストール・更新」をダウンロードして開き、インストールします。
  5. スタートメニューから「読みあわせ (ScriptSync)」を開き、新規プロジェクトを作成して台本を追加します。

同じ署名証明書を登録済みなら、再登録は不要です。App Installerで開けない場合は、本体のMSIXをダウンロードして開いてください。

今回の更新

  • KotorinToysの管理通信に対応し、起動・画面表示・状態確認・正常停止を受け付けます。
  • 録音・処理・未保存入力・ダイアログ中は管理停止を拒否し、作業を保護します。
  • 本体からの管理操作は現在、開発EXEで対応しています。インストール済みMSIXの本体管理は今後の対応です。

0.0.6系列の改善

  • 原稿再読込後の下書き保存と、重複行の安全な対応付けを改善しました。
  • 採用取消、別原稿へのテイク移動、前後編集と途中削除の試聴編集に対応しました。
  • 録音・出力画面へ待ち時間を含む合計時間を表示します。

旧版からの録音、文字起こし、AI文章改善、置換辞書も引き続き利用できます。

動作環境

  • Windows 10 version 2004以降、またはWindows 11（x64）
  • Microsoft Edge WebView2 Runtime、Microsoft App Installer
  • 録音用マイク

録音と音声出力だけなら、文字起こし環境は不要です。Whisperを使う場合は、設定画面から専用環境を導入します。初回はインターネット接続が必要です。Codexによる文章改善は、Codex CLIの導入と認証が別途必要です。
