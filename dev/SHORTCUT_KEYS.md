# ショートカットキー定義

キー割当・有効条件を変更する際は本書と実装・テストを同時に更新する。Windowsグローバル登録は `src-tauri/src/hotkeys.rs`、動作と状態判定は `src/main.ts`。

## 連続録音

「連続録音を開始」を明示してから登録する。アプリが非アクティブでも動作する。終了、最後の採用、別工程・プロジェクトへの移動、画面リロード復旧・画面消失時に解除する。登録に失敗した場合は開始せずエラーを表示する。

| キー | 収録中 | 保存処理中 | 保存後・待機中 |
| --- | --- | --- | --- |
| F1 | 現在の未保存録音だけを取消し、完了後に同じ発話を再録音 | 保存を中断せず、完了後の追加録音を1件予約 | 同じ発話へ追加録音。保存済みテイクは削除しない |
| F2 | 停止して保存 | 無効 | 無効 |
| F3 | 無効 | 無効 | 直前の保存済みテイクを再生。対象がなければ無効 |
| F4 | 無効 | 無効 | 直前の保存済みテイクを採用して次へ。未保存トリミング中なら無効 |

F1の取消完了待ちでの連打は1件にまとめる。開始準備・効果音再生中、確認モーダルの操作中など競合する短い処理では新しい録音を重複起動しない。無効操作では小さな拒否音。ネイティブのMOD_NOREPEATで長押し反復を抑止する。

## アプリ内の補助キー

| キー | 動作 |
| --- | --- |
| Escape | 実行中の処理を停止。確認ダイアログ内ではキャンセル |
| Ctrl+Enter | 表示中の発話で試聴対象／最新テイクを採用して次へ（編集欄入力中は使わない） |
| Alt+←／Alt+→ | 保存済みテイクを切替試聴（編集欄入力中は使わない） |
| Space | 音声再生／停止（編集欄入力中は使わない） |

Ctrl+Rの旧録音開始機能は廃止。F5、Ctrl+F5、Ctrl+R、Ctrl+Shift+Rは再読み込みを抑止し、録音が残って操作不能になる事故を防ぐ。F5をグローバル登録して他アプリの操作を奪うことはしない。

## 復旧

画面の再読込開始・再接続で録音に停止を要求し、途中音声を保存する。画面からの通知が来なくても、最終ハートビートから8秒超でバックエンドが停止を要求する。保存済みテイクを削除せず、保存処理が実際に完了してから操作可能へ戻す。連続モードを自動再開しない。

## 検証

キーの有効条件、取消完了の待機、F1の保存済み保護、保存中の予約、無効音、未保存トリミング時の採用拒否、リロード抑止と再接続復旧を自動テストする。別アプリがアクティブな状態でのキー登録と実マイク可聴品質は実機で別途確認する。
