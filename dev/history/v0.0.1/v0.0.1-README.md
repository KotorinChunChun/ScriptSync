# 読みあわせ (ScriptSync)：開発引き継ぎ

作成日：2026-09-07。状態：開発基盤準備済み・機能未実装。`v0.0.1` は新ツールの初期計画番号で、TextToSpeech CLI本体の版とは無関係。アプリ名はユーザー指定の「読みあわせ (ScriptSync)」、リポジトリは `C:\develop\ScriptSync` とする。

漢字表記による自然なイントネーションを残すため、人間の録音と原文合成音声をひらがなで照合し、確認した誤読箇所だけを局所補正する。人間の声色やアクセントを複製するツールではなく、人間の発話を読みの基準にする制作支援ツールである。

## 開発開始時の依頼文

> README、dev/v0.0.1-req.md、dev/v0.0.1-imp.md、目的別のdocsを読み、タスク表に沿って実装してください。最初にP0の接続・実発話文字起こし・原文位置対応を検証し、その結果に従ってP1以降へ進めてください。音声生成には外部のTextToSpeechCLI.exeを設定パスで利用します。原文・正解読み・AIが実際に発した読みを別々に保持し、文字起こしの不一致だけで原稿を自動確定しないでください。段階ごとに検証し、日本語で記録・コミットしてください。未採点音声を品質合格にしないでください。
