## 実装済みの要求（実機の未確認範囲は別記）

| ID | 要求 | 受入条件 |
| --- | --- | --- |
| R301 | 録音終了後、録音画面で自動文字起こしを行う | 既存のfaster-whisperを使用し、録音終了後にローカルで自動実行する。録音中の逐次表示は不要。全ての新規録音テイクを対象とする。結果をテイクごとに表示し、失敗時に再認識できる |
| R302 | テイクの編集・保存後、開始位置を再編集しても保存できるようにする | 開始位置を変更して保存した後、再度別の有効な開始位置へ変更すると保存ボタンが表示され、再保存できる。保存した開始位置が再表示後も保持される |
| R303 | 録音画面で空の台本行を挿入できる | 本文が空の台本行を録音画面から挿入でき、その行を選択して録音できる。録音用に明示的に挿入した空行は、本文が空であることを理由に一覧から除外しない |
| R304 | 台本が空のとき、録音後の文字起こし結果を台本へ自動入力する | 空の台本行で録音を終了すると、既存のfaster-whisperによる文字起こし結果をその行の読み上げ用本文と台本下書きへ自動入力する。確定済みの比較基準は更新しない。既存本文と認識待ち中の手入力は上書きしない |
| R305 | 差分確認に「すべて承認」と、その右に「すべて解除」を設ける | 個別の操作ボタンは「承認」のみとする。選択中ファイルの「すべて承認」で承認フラグをまとめて設定し、「すべて解除」でそのファイルの承認した状態をまとめて取り消す。個別解除・却下・すべて却下は設けない。承認と解除はフラグの変更であり、差分比較の基準本文を更新しない |
| R308 | 左端に台本ファイル一覧を置き、横方向の4ペインとする | 左から「ファイル一覧」「台本の内容表示・編集」「差分を確認する」「読み上げ対象を選ぶ」を横に並べる。ファイル一覧で選択したファイルの内容を表示する |
| R309 | 台本ファイルを追加登録でき、空の台本も追加できる | 登録件数に固定の上限を設けず、後から追加登録できる。ファイル読み込みに加え、内容が空の台本も作成・登録できる。無制限は件数制限を設けない意味で、物理資源が無限であることを要求しない |
| R310 | ファイル名・取り込んだ本文・ファイルの並び順を内部で保持する | 取り込んだ全台本を記憶し、再読込時に同一ファイル名を既存台本として対応付け、登録済みのファイル順を維持する。同名でも本文の変更は差分比較の対象とする |
| R311 | ファイル順に本文を連結した台本を基準に、差分確認と読み上げ対象の選択を行う | ファイルの並び順と各ファイル内の行順に従って全体の順序を構成する。選択ファイルの内容を表示しながら、この順序を保持して差分確認・読み上げ対象の選択を行える。読み上げ対象側で独立した並べ替えは行わない |
| R312 | 最後に「台本確定」した本文を基準に、ファイル名単位で差分比較する | 同名ファイルについて、最後に右下の「台本確定」ボタンで確定した本文と、再読込・編集した本文との差分を表示する。読込・承認・すべて解除だけでは比較基準を更新しない。承認後に「台本確定」を実行し、確定が完了した本文を次回以降の比較基準とする。複数ファイルの本文を混ぜて照合しない |
| R313 | 読み込み方法の切替を廃止し、登録台本の順序に従う | 「末尾に追加」「差分として読み込む」などのモード選択を不要とする。同名ファイルは既存台本の差分比較、新しいファイルは追加登録として扱い、全体は登録台本の並び順に従う |
| R314 | ファイル一覧のファイルをドラッグで並べ替えられる | ファイル一覧でファイルをドラッグして順序を変更できる。変更後のファイル順に本文を連結し、差分確認・読み上げ対象の順序にも反映する。ファイル内の行順は保持する |

## 既存要件との矛盾・調整事項

- v0.0.2 R202と補足の「ファイル名に依存しない」「取り込み元名の永続管理は不要」「複数入力を一つの原稿として照合」は、R310・R312と矛盾する。今回の変更ではファイル名を保持し、同名ファイル内で比較する仕様へ置き換える。
- v0.0.2 R205・R217の原稿全体での行移動・対応付けは、ファイル順を優先するR311・R312に合わせて適用範囲を同じファイル内に限定して実装する。ファイルをまたいだ行対応付けは行わない。
- v0.0.2 R222の「承認／却下」は、R305の「個別承認、すべて承認、すべて解除」に置き換える。台本確定は全ファイルを対象とし、未承認の差分が残る間は確定しない。
- v0.0.2 R220・R223の3ペインと左ペイン内の読み込み方法は、R308の横方向4ペインと読み込み方法の切替廃止へ置き換える。ファイル選択は別画面への遷移ではなく左端のペインで行う。
- v0.0.2の本文が空の行を除外する規定・R219の空行差分無視は、明示的に追加する空の台本・録音用空行まで消す扱いにはできない。通常のMarkdown空行と、意図して追加した空台本・空行を区別して保存する。
- R303・R304の空行への録音・自動入力は継続する。文字起こし結果は読み上げ用本文と下書きへ反映し、確定済みの比較基準は変えない。空行の所属は選択中の発話またはファイルに従う。
- 同一ファイル名で維持する対象は、台本の登録とファイル順を確定済みとする。変更行のテイク・読みは、同じファイル内の対応先と維持を明示した場合に保持する。新規として扱う場合は旧行をアーカイブする。

## 確定済みの補足（2026-09-10）

- 一括承認・解除の対象は選択中のファイル。台本確定は全ファイルが対象で、未承認差分が残る間は確定しない。
- ファイル順はファイル一覧でドラッグ変更する。読み上げ行のドラッグは廃止。
- 比較基準は最後に台本確定した本文。承認フラグ・通常保存・録音では基準を進めない。
- 全ての新規録音テイクを既存faster-whisperで認識し、空欄のみ読み上げ用本文と台本下書きへ入力する。手入力は上書きしない。
- 元ファイル名のない既存プロジェクトは1つの「既存台本」として録音ごと保持し、元ファイルの対応確認後に分割・再登録する。

## 実装判断（2026-09-10、ユーザー回答とは区別）

以下は実装開始指示を受け、確定要件を満たすために採用する既定動作。利用者が明示した決定と混同しない。

- 新規ファイルは末尾へ登録し、その後ドラッグで並べ替える。一部再読込で未指定の登録台本を削除しない。
- 照合名は拡張子込みのファイル名。同一取込内で重複する名前は拒否する。同名を後から読み込むとその台本の更新候補とする。改名したファイルは新規登録になる。
- 取り込み直す台本に未確定の手編集がある場合は、そのまま上書きせず確認する。確認取消では下書きを保持する。
- 空台本には重複しない仮名を付ける。録音用空行は選択した発話と同じファイルの直後へ挿入し、選択がなければ選択ファイルの末尾に挿入する。
- 空白だけの本文は空欄として扱う。複数の認識結果では、現在の本文が空で開始時の本文版が一致する結果だけを入力する。先に入力された本文を後続結果で上書きしない。
- 認識結果はテイクごとに保存・表示する。失敗しても録音を保持し、再認識できる。録音を優先し、認識ジョブは録音と独立して管理する。
- ファイル削除や名前変更の専用UIは今回の明示要件ではないため追加しない。台本本文から削除された行のアーカイブ保持は継続する。

## 文字起こしエンジンの選定記録

採用：既存のfaster-whisper。以下は選定時に提示した候補の記録であり、複数エンジンの導入・切替を要求するものではない。

2026-09-09に公式資料を確認。認識精度や待ち時間は本プロジェクトで比較未実施。

| 候補 | 実行場所 | 選定上の特徴 |
| --- | --- | --- |
| [faster-whisper](https://github.com/SYSTRAN/faster-whisper) | ローカル | 既存ASRで使用しているため第一候補。Python環境を使用し、CPU/GPUと8ビット量子化に対応 |
| [whisper.cpp](https://github.com/ggml-org/whisper.cpp) | ローカル | C/C++実装。Windows、CPU、CUDA・Vulkan等に対応。Python依存を減らす方向の候補 |
| [Azure AI Speech](https://learn.microsoft.com/en-us/azure/ai-services/speech-service/language-support) | クラウド | 日本語の音声認識に対応。サービス接続・認証・音声送信が必要。料金と利用条件は採用検討時に確認 |

faster-whisperとwhisper.cppは同じWhisper系モデルを動かす別実装であり、別系統の認識モデルではない。ユーザー指定により、既存環境を活かすfaster-whisperを採用する。
