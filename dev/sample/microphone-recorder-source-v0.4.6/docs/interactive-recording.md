# 検証用音声を対話録音する

開発用CLIで、室内音・通常声・小声・大声・発声前後の余白など10種類を収録できます。`--interactive`でブラウザーのクリック操作画面が開きます。実マイクでの最終確認は未実施です。

別プロジェクトへ見本ソースと関連資料をコピーする場合は、[ソース見本一式の作成と移植](microphone-recorder-source.md)を参照してください。

```powershell
cd C:\develop\VoiceMixer
cargo run --manifest-path src/src-tauri/Cargo.toml --bin microphone-recorder -- --interactive
```

最初にマイクを選びます。以降は台帳に保存した同じマイクを使い、なくなった場合は他の機器へ自動切替しません。保存先を固定指定する場合は`--directory`、機器を指定する場合は`--device`または`--endpoint-id`を追加します。開発リポジトリ内から実行した場合の既定保存先は`dev/private/audio-samples/`、それ以外はユーザーのLocalAppData配下`VoiceMixer/audio-samples/`です。

画面でマイクを選び、課題文または「録音」をクリックします。停止・録り直し・確認再生・全無音の0.1秒短縮・短縮版再生・採用をボタンで操作できます。起動しただけでは録音しません。終了ボタンで録音とローカルサーバーを停止します。画面は127.0.0.1の一時ポートと操作トークンを使用します。

番号＋Enter方式を使う場合は`--interactive --console`にします。次の表は番号操作用です。

| 操作 | 入力例 | 動作 |
|---|---|---|
| 録音・録り直し | `2` | 2番の課題を開始。既定10秒で停止 |
| 途中停止 | Enterまたは`s` | 録音を終了して保存 |
| 確認再生 | `p 2` | 2番の最新の録音を既定再生デバイスで試聴。Enterで停止 |
| 無音短縮 | `t 2` | 最新の原本から全検出無音を0.1秒へ短縮した別WAVを作成 |
| 短縮版再生 | `d 2` | 最新の短縮版を試聴 |
| 品質警告のある録音を採用 | `a 2` | 最新の失敗していないテイクを採用 |
| 終了 | `q` | 台帳を残して終了 |

Peak/RMSとクリッピング・小音量の警告を表示します。室内音だけの課題は小音量を失敗扱いしません。録り直しは別ファイルになり、古いテイクも残ります。`p`は採用済みテイクに限らず、最新の失敗していないテイクを再生します。

`session.json`に課題本文、録音日時、マイク、音声ファイル名、品質、採用テイク、短縮版と原本の対応を記録します。個人音声・台帳はGit追跡対象外です。

無音短縮の既定閾値は-45 dBで、文頭・文中・文末の100 msより長い無音を100 msにします。片側だけでも発声している区間、元から100 ms以下の間は保持します。次の操作で判定を調整できます。

```text
settings -45 100 10 -40
```

順に「無音閾値dB、最短無音ms、発声端の余白ms、小音量警告の閾値dB」です。原本は上書きせず、再短縮も原本から行います。ゲートの開閉時間・長い無音・室内音の評価には原本を使ってください。
