原稿単位の対応付けは「どの記憶済み原稿の更新として扱うか」を指定する意味として整理する。名前一致をその指定に使い、別の選択UIの追加は未確定とする。完全消去の操作単位等の画面細部は設計案として扱う。
## 実装済

UI試験132件、Rust試験87件成功（外部環境4件ignored）。ネイティブ画面の操作・再読込を確認。詳細は実装記録を参照。

| ID | 要求 | 受入条件・補足 |
| --- | --- | --- |
| R404 | 各ペインの見出しを変更する | 第1は「原稿を登録する」（縮小時も同じ名称）。第2は「原稿を閲覧／編集する」、第3は「差分を確認する」を維持、第4は「読み上げ対象を選択する」 |
| R405 | 第1ペインを折りたたみ・展開できる | 右上のボタンで極端に狭くし、再押下で元の幅に復元。縮小中もファイル名の先頭約3文字と「確認済み」「未確認○件」の状態文字を残す。この2要素を表示できる幅を基準にし、見出し「原稿を登録する」は全て見えなくてもよい。見出しを「ファイル」に置き換えない |
| R406 | ファイル名を折り返さない | 展開中・縮小中とも1行表示。狭いときも複数行にしない。ユーザー記載「開業もオフ」は文脈上「改行・折り返しなし」として記録 |
| R407 | 第2ペインも折りたたみ・展開できる | 右上のボタンで極端に狭くし、再押下で元の幅へ復元。第1・第2をそれぞれ操作できる |
| R408 | 一括承認ボタンを差分上部の右端に移動する | 「すべて承認」「すべて解除」を下部から、追加・削除行数ラベルと同じ段の右端に移す。発言中の「左上」は後続の「右上」で訂正済み |
| R409 | 一括承認の操作・行数表示を大きくする | 両ボタンの大きさ・文字サイズと「追加○行／削除○行」の文字を現行より大きくする |
| R410 | 全件承認状態を色で示す | 全件承認後は「すべて承認」の緑と白の背景・文字を入れ替え、既存の個別承認ボタンと同じ承認済み表示にする |
| R401 | 登録済み原稿と空から作った原稿の名前を編集できる | 選択した原稿でF2を押すと名前がテキスト入力になり、Enterで確定する。「名前変更」ボタンも同じ編集を開始する。変更はプロジェクト内だけで、ディスク上の元ファイルは変更しない。読込後の原稿名同士で照合する。同名への変更はR415のマージへ進む |
| R402 | 1つ目のペインのボタンを整理する | 見出しの下へ「開く」「新規」「名前変更」「削除」の順に配置。「ファイルを登録」は「開く」、「空の原稿」は「新規」に改称する |
| R403 | 選択原稿を削除できる | 「削除」ボタンで削除予定とし、「台本確定」を押した時点で原稿を削除する。読み・テイクはアーカイブへ保持できる。完全消去はR417の別操作 |
| R411 | 読み上げ対象の説明を表示する | 見出し直下に「読み上げる必要がない文章については文字をクリックして取り消し線を引いてください」と表示。文章クリックによる対象外切替と取り消し線が対応する |
| R412 | 原稿と対応付け操作を横並びにする | 各行の本文の右側へコンボボックスを常時表示。本文の下へ交互に操作を並べず、折りたたみツリーも使わない。「既存の発話・読みを維持する」という説明ラベルを削除 |
| R413 | 対応付けの表示と候補を絞る | 新規の表示は「(新規)」。自動一致した行だけコンボボックスをグレーアウトして操作不可とする。手動対応は変更可能。候補は今回の削除行に加えて過去のアーカイブ行も含め、マッチ済みの行は出さない |
| R414 | 対応付け自体を既存データ継承の意思表示とする | 「この発話の既存の読み・テイクを維持する」チェックを削除。対応付けたら既存の読み・テイクを使い、使わない場合は「(新規)」にする |
| R415 | 名前の不一致を直し、同名取り込みと同じ差分処理へ進む | 実体ファイル名と本ツールが記憶した原稿名の食い違いを、取込後の名前変更で合わせる。名前が既存原稿と一致したら、最初からその名前で取り込んだ場合と同じ差分比較・承認・台本確定へ進む。独立した原稿同士の専用マージ規則は追加しない |
| R416 | 対応が途切れた過去データの一覧画面を用意する | 過去に削除され、現在の原稿・読み上げ行との接続がないデータを別画面で一覧できる。そこからアーカイブの完全消去を行える |
| R417 | アーカイブから原稿・音声を含めて完全消去できる | 一覧で対象データを選び、原稿と関連音声を含めた完全消去を行う。通常の原稿削除とは別操作。対象は本プロジェクト内に取り込まれたデータのみ。登録前のオリジナルファイルは残し、その保存場所は本ツールで記憶しない |
| R418 | 起動画面の5フローの矢印形状と文字を改善 | より明確な角度を付け、文字を一段大きくする。新規プロジェクト・開くの下の説明は削除 |
| R419 | 起動画面へのプロジェクトドロップ | .scriptsyncをドロップすると「開く」と同じ処理で開く |
| R420 | インストール時に独自拡張子を関連付け | .scriptsyncから本アプリでプロジェクトを開ける |
| R421 | 台本画面へのフォルダードロップ | サブフォルダーを含むMD・TXTを取り込む。元ファイルの場所は保持しない |
| R422 | 原稿ファイルのドラッグ並び替え | クリックしてドラッグし、ファイル順を変更・保存できる |
| R423 | 読み上げ対象のドラッグ並び替え | 選択中の原稿内の読み上げ順だけを変更。元の原稿本文の行順は変えない |
| R424 | 原稿全文の左右差分表示を追加 | 左に旧原稿、右に新原稿、削除赤・追加緑。空きセルで行を整列し同期スクロール。各変更を承認可能。変更箇所のみ表示と切替 |
| R425 | 台本確定後に録音タブへ移動 | 確定成功時に移動し、失敗時は台本画面に留まる |
| R426 | 選択原稿の編集を取り消す | 編集ペインに復元ボタンを置く。ファイル取込時・プロジェクトを開いた時・台本確定時の原稿へ戻す |
| R427 | 左上のプロジェクト名をクリックして変更 | アプリ名の代わりにプロジェクト名を表示。クリックで入力、Enterで決定。ウィンドウタイトル、プロジェクトファイル、付随データフォルダーも連動 |
