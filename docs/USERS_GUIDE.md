# 利用者ガイド（v0.0.1）

完成版0.0.1を基本とし、台本画面は0.0.2開発版の操作を記載しています。

## プロジェクトを作る・開く

ビルド済みの `src-tauri/target/release/scriptsync.exe` を起動します。開発起動は[開発者ガイド](DEVELOPERS_GUIDE.md)を参照してください。

「新規プロジェクト」で保存先と `.scriptsync` ファイル名を指定します。次回は「開く」でそのファイルを選びます。作成・開くが成功したフォルダーを次の選択の既定位置として記憶します。台本TXT/Markdownや、その親フォルダーを選ぶ操作ではありません。

例えば `収録.scriptsync` と隣の `収録.scriptsync.data/` が一組です。移動・バックアップでは両方をまとめてコピーし、データフォルダー内のファイル名を手作業で変更しないでください。コピー前にアプリを終了します。同じプロジェクトの同時編集はできません。

## 1 台本

v0.0.2開発版は左から「読み込む・編集する」「差分を確認する」「読み上げ対象を選ぶ」の3ペインです。境界を左右へドラッグするか、境界にTabでフォーカスして左右キーを押すと幅を調整できます。

1. 左ペインの「Markdownを読み込む」、貼り付け、またはMarkdown/TXTのドロップで入力します。ドラッグ中は読込先を強調表示します。「差分として読み込む」は確定済み原稿との変更を比較し、「末尾に追加」は入力中の原稿へ追記します（既定）。確定前に2本目を読んでも1本目の下書きが残ります。複数ファイルは名前順に結合します。UTF-8、合計2MB・100ファイル以内に対応します。
2. 中央の各変更で「承認」か「却下」を選びます。＋は追加、−は削除です。削除を却下すると旧文が残り、追加を却下すると新文を取り込みません。空行の増減は差分に数えません。入力や判断は自動更新され、手動更新ボタンはありません。
3. 右ペインで確定予定の読み上げ対象をオン／オフにします。未承認の削除は残り、未承認の追加は入りません。選択は確定まで下書きです。
4. 未確認が0件になってから下部の「台本を確定」を押します。確定までは保存済み台本や録音を変更しません。

H1は部、H2は章、H3は節、箇条書きは項です。コードブロック・画像・表などは既定でオフです。空本文は対象一覧に表示しません。2本目の原稿だけを読み込んだ場合、既存原稿の削除を却下し、新しい行の追加を承認すれば両方を残せます。

完全一致で保持した行は、先頭追加で行位置が変わってもID・テイク・採用・録音用の編集を引き継ぎます。本文の変更は削除と追加を別々に扱い、削除承認した旧行は履歴へ、新規行はテイクなしになります。類似文への手動対応付けやアーカイブ管理の全機能はまだ準備中です。

## 2 録音

Windowsのシステム設定で入力マイクを選びます。アプリは録音開始時に既定マイクを読み直します。

1. 発話を選んで「録音開始(F1)」を押し、原稿を読みます。
2. 「停止して保存(F2)」で新しいテイクを保存します。「延長」は停止要求後も収録を続ける秒数で、既定0秒、0～60秒です。
3. テイクを試聴し、良ければ「採用して次へ」を押します。最後の発話まで採用すると読み確認へ進み、録音タブに「（完了）」を表示します。

通常モードでは次へ移動しても録音は自動開始しません。前へ／後へは端で無効になり、巡回しません。1回の録音上限は5分です。入力レベル、収録中の波形、経過時間を録音欄に表示します。

「取り消し」は現在の未保存録音だけを破棄します。保存済みテイクは消しません。保存時には前後の無音を切り、各0.1秒を残します。途中の無音は切りません。停止延長中の無音も保存時の端部カット対象です。

### キーと連続録音

| キー | 通常録音（本アプリがアクティブ） | 連続録音 |
| --- | --- | --- |
| F1 | 待機中は開始、録音中は取消して待機 | 取消して同じ発話を再録音。待機中は追加録音 |
| F2 | 停止して保存 | 停止して保存 |
| F3 | 最新の保存済みテイクを試聴 | 同左 |
| F4 | 最新テイクを採用して次へ | 採用して次へ進み、自動で次の収録を開始 |

「連続録音を開始」を押した間だけ、他アプリを操作中でもキーを検知します。「連続録音を終了」、工程移動、最後の採用、画面復旧で監視を解除します。保存中など使えないキーでは小さい効果音が鳴ります。詳細・補助キーは[キー定義](../dev/SHORTCUT_KEYS.md)を参照してください。

### テイクの調整

通常録音の開始(F1)ボタンは収録中に取り消し(F1)へ切り替わります。テイクの試聴ボタンは再生中に停止へ変わり、最新テイクはF3でも試聴／停止を切り替えられます。

波形の左右ハンドルで残す範囲を指定します。開始／終了の数値欄でも0.01秒刻みで調整でき、入力直後にバーも動きます。試聴は指定範囲の終了で止まります。

変更中は「保存・試聴・削除」を表示し、採用を隠します。「保存」で音声を実際に切り詰め、波形・総時間を更新し、両端を新しい音声の先頭／末尾へ戻します。元に戻す操作はありません。未保存のまま移動すると保存・破棄・戻るを選べます。

テイクメモは入力欄からフォーカスを外すと保存します。隣の「評価」は未評価と0～100点の10点刻みから選べ、選択直後に保存します。評価は採用状態と独立しています。削除はアプリ中央の確認後に実行します。採用ボタンは強調色で表示し、F3/F4の表示は最新テイクだけに付きます。

録音用原稿の句読点や漢字の読み替えは編集でき、フォーカスを外すと保存します。元原稿・編集後・録音時の原稿は別に保持します。録音工程では文章の分割をしません。

### ノイズと復旧

欠落を検知した録音は「要確認」として、不連続・リング欠落・補償時間等を表示します。診断値は通常色で表示します。採用前の確認では緑色の「採用」が既定で、Enterで採用、Escapeで戻れます。

F5やCtrl+R系の再読み込みは無効です。予期しない再読み込みでは収録を停止・保存して操作を復旧し、連続録音を自動再開しません。保存完了までは処理中表示が続きます。

## 3 読み確認・補正（任意）

採用音声を聴き、正解の読みを確認します。ローカル認識は下書きと時刻候補を作ります。「読みの下書きへ」を使った後も、実際の音を聴いて修正・確定してください。

原文の対象語を選択し、正しい読みとの対応を登録します。同じ語が複数ある場合は位置ごとに扱います。補正候補は採用・却下・保留を選べます。他発話の補正事例も、文脈を確認して利用します。一括認識はこの工程にあります。

ASRは誤読を正しい漢字へ戻してしまうことがあるため、認識一致を正しい発音の証明にしません。

## 4 比較・採点（任意）

TextToSpeech CLIを準備して、原文・全文かな・局所補正を同じ声条件で比較します。Codex提案を使う場合は原稿をCodexへ送ります。音声認識はローカルです。接続環境は[開発者ガイド](DEVELOPERS_GUIDE.md)を参照してください。

候補は匿名順に提示され、試聴後に「候補名を開示」できます。正確さ・自然さ・アクセント・抑揚と間・感情を1～5で採点し、判断できない項目は未採点にします。一括合成、読点比較、補正ルールの検証もこの作業に関連します。

CLI側の音声合成エンジン編集形式は限定条件の試験対応です。[形式と検証範囲](talk-project-format.md)を参照してください。

## 5 結合・出力

録音の採用が揃えば工程3・4を飛ばして進めます。この工程には左の原稿ツリーを表示せず、出力用の一覧を使います。

1. 分割単位を全体・部（H1）・章（H2）・節（H3）・発話から選びます。行端のハサミ／連結アイコンで境界を追加・解除すると手動設定になります。
2. 本文をクリックしてブロックを選択します。未選択の背景はベージュ／青紫の交互2色で、選択ブロックは緑になります。
3. 命名規則はなし・日本語・2桁数字から選びます。先頭4桁の連番と階層は固定で、本文由来の名前だけ編集します。使用不可文字を自動除去し、本文部分は先頭20文字に制限します。空になる場合はscriptになります。形式を切り替えると拡張子も変わります。
4. 「挿入する無音時間」を部・章・節・通常の発話間・ファイル先頭・末尾の順に設定します。ブロックごとに既定／手入力を選択でき、既定欄は無効表示になります。ファイルが別になる境界には発話間の間隔を足しません。
5. 音量を均一にするチェックを選び、「最初から再生」は全体、「選択ブロックを試聴」はそのブロックだけを生成・再生します。「選択ブロックの最後の項から試聴」は従来どおり後続ブロックも続けて再生し、つなぎ目を確認できます。原音を確認するときはチェックを外します。原稿・採用音声・設定が変わらなければ生成済みの試聴音声を再利用します。準備中は「音声データを生成中」、再利用した再生時はキャッシュ使用を表示します。再生は隣の「停止」で止められます。
6. FLACまたはWAVを選び、「音声ファイルを出力」。同じ名前のVTT字幕と、連携用のblock-map.jsonもセットで出力します。「出力フォルダーを開く」は出力前にも使用でき、その場合は出力の親フォルダーを開きます。出力後はその回の音声・字幕があるフォルダーを開きます。

ファイルはプロジェクトのデータフォルダー内 `exports/<出力ID>/` に作られます。未採用・音声差替えなどがあれば出力を止めます。字幕は1発話1区間で、トリムと結合間隔に合わせた時刻・読み上げ原稿を記録します。例：`0001_原稿.flac`と`0001_原稿.vtt`。元テイクは出力のために変更しません。MP3/M4A出力は現在ありません。

プレゼンテーションソフトとの連携には[ブロックマップ形式仕様](EXPORT_BLOCK_MAP.md)を参照してください。ブロック順序・所要時間・発話区間と全文を読み取れます。
