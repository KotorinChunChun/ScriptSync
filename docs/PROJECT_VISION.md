# 読みあわせ（ScriptSync）プロジェクトビジョン

更新日：2026-09-13

## 目指す姿

頻繁に更新される原稿から読み上げ用の台本を作り、変更箇所の録り直し、テイクの採用、合成音声の読み合わせ、プレゼンテーションや動画編集に使うファイルの出力までを、一続きの作業として行えるようにする。

原稿の変更をすぐに台本へ反映し、必要な箇所の収録に戻れることを中心に、次の4つを本システムの役割とする。

## 1. 原稿の変更に追従する台本作成

原稿から、実際に読み上げる文章を整理した台本を作成する。原稿は頻繁に書き換えられることを前提とし、更新前後の差分を確認して、読み上げるべき内容を簡単に台本へ反映できるようにする。

変更された箇所と録り直しが必要な箇所を把握し、台本の更新からリテイク録音へすぐに進めるようにする。必要に応じて台本をスマートフォンへ送り、スマートフォンでも録音できるようにする。

## 2. 台本に沿った録音とテイクの採用

台本の発話ごとに録音し、間違えた箇所や改善したい箇所だけを取り直せるようにする。複数のテイクを聴き比べ、最も良いものを正式な採用テイクとして選ぶ。

原稿と録音の対応、過去のテイク、採用結果を保持し、これまでの作業を生かしながら、台本の更新と録り直しを繰り返せるようにする。

## 3. 合成音声と発声読み仮名の一致

合成音声が実際に発している読みと、台本で意図した発声読み仮名を揃える。人間が確認した読みを基準として、合成音声との違いを確認し、必要な箇所を補正できるようにする。

原文の漢字や文脈を生かしながら誤読箇所を局所的に補正し、読みの正確さと音声としての自然さを確認する。

## 4. プレゼンテーション・動画編集に向けた結合とエクスポート

台本に対応する採用音声を組み立て、プレゼンテーションで必要な切り替えのタイミングに合わせて、音声の切れ目や待ち時間、発話間の間を調整できるようにする。

用途に適した単位で音声を結合・分割し、必要な間を追加して音声ファイルを書き出す。併せて、字幕ファイルや切り替え位置・時間情報など、プレゼンテーションや動画編集に必要なファイルをエクスポートできるようにする。
