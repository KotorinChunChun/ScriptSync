# Webへの台本アップロード（v0.0.5）

台本画面で原稿を選び「台本確定」を押します。そのまま画面に留まるので、右隣の「ウェブ版にアップロード」を押してください。「ウェブ版用にエクスポート」はローカルへのZIP保存です。出力方式のプルダウンはありません。再編集した場合は、再確定するまで両方のボタンが無効になります。

送信画面ではHNと数字6桁のキーを入力し、「台本ZIPを送信」で確認します。同じHNとキーを[ScriptSyncWeb](https://dev-k.sakura.ne.jp/tools/scriptsyncweb/)へ入力すると取得できます。選択した原稿1件の確定本文・有効な読み上げ行を送信し、既存テイク音声は含めません。

## 保存の仕組み

アプリは暗号化ZIPをHTTPSの専用APIへ送信し、PHPがサーバー自身の書込権限で保存します。利用者のFTPアカウント・サイト編集権限は不要です。現在のAPIは未登録HNを初回送信で作成し、既存HNでは対応するキーを照合します。利用者ごとの管理者承認方式ではありません。

ZIPはAES-256で暗号化し、HNとキーからPBKDF2-SHA256で認証トークンを生成します。512KiBずつ転送し、サーバーの保存完了応答を確認します。キーは端末設定へ保存しません。保存期限24時間、ZIP上限100MiBのほか、保存数・容量・認証試行の制限があります。通信エラー時は成功扱いせず、今回の転送予約だけの削除を試みます。

## アプリ外のファイル管理

OneDrive・Boxの認証、設定、直接アップロードはありません。利用者がZIPを出力し、必要なサービスへ自分で保存してください。以前のクラウド上のファイルやアカウントは変更しません。

## 検証範囲

ローカルAPI契約と暗号化・分割転送・失敗処理は自動試験で確認します。公開サーバーへの実送信結果と今回の検証記録は[v0.0.5実装記録](../dev/v0.0.5-imp.md)を参照してください。コード検査だけで実送信成功とは判断しません。
